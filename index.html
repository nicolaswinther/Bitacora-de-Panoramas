Sincronización en tiempo real

Estado: solo este celular (sin conectar).

¿Cómo consigo esto? (5 min, gratis, sin tarjeta)
  1. Entra a console.firebase.google.com con una cuenta de Google y crea un proyecto nuevo.
  2. En el menú lateral ve a Build → Firestore Database y crea la base de datos (modo producción está bien).
  3. Dentro de Firestore, pestaña Reglas, pega esto y publica:
    match /rooms/{room} { allow read, write: if request.auth != null; }
  4. Ve a Build → Authentication → Sign-in method y activa el proveedor Anónimo.
  5. Ve a Configuración del proyecto (⚙️) → en "Tus apps" agrega una app Web (ícono </>).
  6. Copia el objeto firebaseConfig que te muestra y pégalo arriba.
  7. Inventen un código de pareja y escríbanlo igual en ambos celulares.
